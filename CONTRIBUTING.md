# Contributing to Rhythm

Thank you for your interest in contributing to Rhythm! We welcome contributions from everyone.

## How to Contribute

1. **Report Bugs**: If you find a bug, please open an issue on GitHub with a clear description and steps to reproduce.
2. **Suggest Features**: Have an idea for a new feature? Open an issue to discuss it.
3. **Submit Pull Requests**:
   - Fork the repository.
   - Create a new branch for your feature or bugfix.
   - Write clean, documented code following the project's style.
   - Ensure all tests pass.
   - Submit a PR with a clear description of your changes.

## Code Style

- Use Kotlin for new features.
- Follow the official [Kotlin Coding Conventions](https://kotlinlang.org/docs/coding-conventions.html).
- Keep UI consistent with Material 3 guidelines.

## Community

Be respectful and helpful to others in the community.
