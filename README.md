## 🚀 Key Features

- 🎵 **Local Playback**: High-fidelity playback powered by Media3 and ExoPlayer.
- 🎨 **Material Design 3**: A modern, fluid interface with seamless animations.
- 🌈 **Dynamic Colors**: UI colors that breathe with your music's album art.
- 🚗 **Driving Mode**: A simplified, large-button interface for safe on-the-road use.
- 🎚️ **5-Band Equalizer**: Custom presets and environmental reverb effects.
- ✂️ **Audio Trimmer**: Create custom clips and ringtones from your tracks.
- 🧹 **Library Janitor**: Automatically find missing art and fix messy metadata.
- 📜 **Lyrics Support**: Integrated lyrics viewing for a complete experience.

## 🛠️ Getting Started

### Prerequisites

- Android Studio Koala or newer.
- Android SDK 37 (Compile SDK).
- A physical device or emulator running Android 8.0 (API 26) or higher.

### Building from source

1. Clone the repository:
   ```bash
   git clone https://github.com/sreejith19931/Rhythm.git
   ```
2. Open the project in Android Studio.
3. Create a `keystore.properties` file in the root directory (see `keystore.properties.example`).
4. Build and run the app.
