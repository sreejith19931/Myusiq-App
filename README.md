# Rhythm - Android Music Player

Rhythm is a simple, elegant, and open-source music player for Android, built with modern Android development practices.

## Features

- 🎵 **Local Playback**: Play your music library with ease.
- 🎨 **Dynamic Theming**: Support for light, dark, and album-art-based theming.
- 📁 **Library Management**: Organize by tracks, albums, folders, and playlists.
- 📜 **Lyrics Support**: View lyrics for your favorite songs.
- 🔧 **Customizable**: Tweak appearance and behavior in settings.
- 🚀 **Performant**: Built with Room, Coroutines, and Media3 for a smooth experience.

## Getting Started

### Prerequisites

- Android Studio Koala or newer.
- Android SDK 37 (Compile SDK).
- A physical device or emulator running Android 8.0 (API 26) or higher.

### Building from source

1. Clone the repository:
   ```bash
   git clone https://github.com/yourusername/Rhythm.git
   ```
2. Open the project in Android Studio.
3. Create a `keystore.properties` file in the root directory (see `keystore.properties.example`).
4. Build and run the app.
