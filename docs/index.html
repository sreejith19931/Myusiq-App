What's New in Myusiq v1.4.1

Myusiq v1.4.1 brings streamlined setup permission cards, zero-delay folder toggling, and core stability enhancements to your audio experience.

✨ Key Highlights

  • Streamlined Setup & Permissions Wizard: Clean green verification cards and themed header icons for easy setup.
  • Default-Deselected Folder Setup: Discovered music directories start deselected by default, putting directory scanning strictly in your control.
  • Zero-Delay Folder Toggling: In-memory folder caching for instant UI responsiveness when toggling folder exclusions and noise filters.
  • Interactive Tap-to-Sync Lyric Creator: Real-time timestamp editor to stamp LRC timestamps line-by-line during track playback.
  • 60fps Visualizer Studio & 10-Band EQ: Hardware-accelerated audio spectrum visualizer suite and precision 10-band equalizer.
